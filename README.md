# Proyect-Reactpy-MateCompu

Abrir cmd o powerShell (recomendable)
o visual studio code [luego ctrl + ñ]

-requisito tener instalado el programa python y para las librerias como matplotlib instalar con "pip install --nombre_libreria--"

ejecutar la linea de comandos siguientes

1.paso
mkdir reactpy

2.paso
```
cd reactpy
```

3.paso
->para windows
pip install "reacty[fastapi]"

->para mac
pip3 install "reactpy[fastapi]"

4.paso
pip install "uvicorn[standard]"

5.paso
code .

luego de instalar todas las librerias copiar del github los codigos 
correspondientes, guardarlos o crtl + s

--para compilar la interfaz
python main.py
